# Matriz de Evaluación Institucional

Aplicación de relevamiento territorial para el Circuito 3.

## Fase actual

Frontend inicial con Next.js, React, TypeScript y Tailwind CSS. La información de instituciones y respuestas se maneja localmente como mock para diseñar y validar la experiencia.

La persistencia, el modelo de datos y la integración con Neon Postgres se definirán en una segunda etapa.

## Desarrollo

```bash
npm install
npm run dev
```
